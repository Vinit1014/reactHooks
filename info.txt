React Hooks

React Hooks are functions that let you use state and other React features in functional components.

Common Hooks:
- useState: Manages local component state
- useEffect: Handles side effects like data fetching, subscriptions, and DOM manipulation
- useContext: Accesses context values without prop drilling
- useRef: Creates mutable references that persist across renders
- useMemo: Memoizes expensive calculations
- useCallback: Memoizes callback functions to prevent unnecessary re-renders
- useReducer: Manages complex state logic with a reducer pattern

Rules of Hooks:
1. Only call hooks at the top level of your component
2. Only call hooks from React function components or custom hooks
3. Hook names must start with "use"

Custom Hooks:
You can create your own hooks to extract and reuse stateful logic across components.
